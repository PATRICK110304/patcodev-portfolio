# Portfolio PatrickDev

Portfolio de **N'Dri Kouakou Patrick Angelin**, développeur front-end à Abidjan.

- **En ligne :** https://patrickdev-portfolio.vercel.app
- **GitHub :** https://github.com/PATRICK110304/patcodev-portfolio
- **Vercel :** https://vercel.com/angelin-projet/patrickdev-portfolio

## Stack

HTML · CSS · JavaScript vanilla · polices Mona Sans et Chivo Mono.

## Projets présentés

- [ZeroRang](https://zerorang.online/) — application web d'inscription scolaire.
- [Northline Commercial](https://northline-commercial-umber.vercel.app/) — site vitrine immobilier d'entreprise premium.

## Lancer en local

```bash
python -m http.server 4173
```

Puis ouvrir `http://localhost:4173`.

## Déploiement

Le projet est relié à Vercel : chaque `git push` sur `main` déclenche un déploiement de production.

```bash
git add .
git commit -m "Mise à jour du portfolio"
git push
```

## Structure

```
index.html          page principale
style.css           styles
script.js           interactions et données projets
public/             images, CV, favicon, image Open Graph
vercel.json         configuration Vercel
.vercelignore       fichiers exclus du déploiement
```
